# Design context

Audience: technical interviewers and engineering hiring managers.
Use case: a prominent standalone live MCP question workspace, with guided investigation of fictional contribution evidence and recorded MCP execution.
Tone: calm, precise, transparent. Light editorial workspace with restrained teal, dark ink, clear typography, and accessible details.
Source of truth: the user's approved implementation plan and PRODUCT.md, updated by the request to place live MCP questions on the homepage. Preserve the guided investigation navigation / findings / evidence-panel composition on investigation pages.
