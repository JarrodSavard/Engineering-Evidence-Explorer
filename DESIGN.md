# Visual system

Surface: guided investigation workspace. Mode: operate/read.

Approved direction: a quiet editorial engineering notebook. Dense evidence remains scannable; a generous Newsreader question establishes hierarchy without a marketing landing page. DM Sans handles interface and body copy. Fonts are self-hosted.

Palette: warm green-tinted paper `#fafbf8`, sidebar `#f2f5ef`, dark green ink `#243c36`, secondary text `#60706a`, teal `#176456`, light rule `#dce3da`. Contributor colors identify people, not quality scores.

Desktop: header, left scenario navigation, central investigation, right source panel. Medium screens move evidence below findings. Mobile stacks navigation, investigation, and source evidence with explicit focus movement and return.

Finding rows use rules rather than card grids. Counts distinguish authorship and review; records use IDs and dates. Disclosure controls contain algorithm detail, tool arguments, and large JSON results. All static/recorded states are visibly named.

Focus uses a visible teal outline. Opening evidence focuses its heading; closing/Escape returns to the originating control. Playback has explicit controls and no autoplay. Reduced motion uses manual steps. No external font or image requests.
